# Clients, their rates, agreed despatch days and retention

Read CLAUDE.md first. Run `npm run fulfil -- clients`. Add `--json` when you need to work with the rows. Present the answer as a short table and one line on what to do next. Drafts stay in drafts/. Nothing sends.
