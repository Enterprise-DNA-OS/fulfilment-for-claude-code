# Put an open order on hold with a reason

Read CLAUDE.md first. Run `npm run fulfil -- hold <order> --reason=<text>`. Add `--json` when you need to work with the rows. Read the affected records before any write, ask the operator when a name matches more than one record, and never invent a quantity, rate, tracking reference or approval. Use for address queries, fraud checks or a client's instruction. The reason shows on the pick wave and in attention after two days.

Present the answer as a short table and one line on what to do next. Drafts stay in drafts/. Nothing sends.
