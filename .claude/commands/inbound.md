# Delivery notices: expected, received and overdue

Read CLAUDE.md first. Run `npm run fulfil -- inbound`. Add `--json` when you need to work with the rows. Read the affected records before any write, ask the operator when a name matches more than one record, and never invent a quantity, rate, tracking reference or approval. Overdue notices are worth a note to the client: what was expected and when.

Present the answer as a short table and one line on what to do next. Drafts stay in drafts/. Nothing sends.
