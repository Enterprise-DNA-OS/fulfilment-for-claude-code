# The stock ledger: receipts, picks, returns and adjustments

Read CLAUDE.md first. Run `npm run fulfil -- movements`. Add `--json` when you need to work with the rows. Read the affected records before any write, ask the operator when a name matches more than one record, and never invent a quantity, rate, tracking reference or approval. Use to explain a count difference. Most recent first.

Present the answer as a short table and one line on what to do next. Drafts stay in drafts/. Nothing sends.
