# Monday review

Run `attention`, `sla`, `low-stock` and `client-review` through `npm run fulfil -- <read> --json`. Write `drafts/weekly-review.md` with four short sections:

1. **Despatch:** on-time percentage per client against their agreed days, and every late order with its cause.
2. **Stock:** SKUs to reorder, grouped by client, and any oversold SKU.
3. **Inbound and returns:** overdue delivery notices and returns waiting over five days.
4. **Clients:** missing rates, clients with no note in 30 days, and the one conversation worth having this week.

Cite order numbers, SKUs and notice names. Never add amounts across currencies. Nothing sends.
