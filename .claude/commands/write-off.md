# Write off a returned item that cannot be resold

Read CLAUDE.md first. Run `npm run fulfil -- write-off <return> --reason=<text>`. Add `--json` when you need to work with the rows. Read the affected records before any write, ask the operator when a name matches more than one record, and never invent a quantity, rate, tracking reference or approval. Record the condition in the reason; the client sees it on the returns note.

Present the answer as a short table and one line on what to do next. Drafts stay in drafts/. Nothing sends.
